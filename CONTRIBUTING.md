# Contributing

Contributions are welcome. Open an issue describing the problem or proposed change, then submit a focused pull request with a description and relevant manual checks. Use English for code, issues and interface text.

For UI changes, check mobile and desktop layouts, keyboard access, empty states, local-storage failures and the distinction between fictional examples and real records. Never add real personal information to fixtures or screenshots.

For a new municipality, propose its official identifier, country, timezone and onboarding plan. Listing a city or organisation does not establish affiliation. Verify a partner and its consent before publishing contact or capacity data.

Report security or privacy issues privately to the maintainer once a security contact is configured; do not publish credentials or personal information in issues.
